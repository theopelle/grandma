**Failure 1 (R1), fixed:** two runs gave reading effort 3 and 1 on the same page. The page's main button jumps down the same page to the tickets section, and SKILL.md did not say how to count that. One run counted every word from the top, the other from where the button lands. Fix (commit "Count reading effort from where a jump link lands"): the word counter now starts from where a jump link lands, and SKILL.md says to count along the path she took. It also says never to use all words when the answer is in skim text, which one run had done.

**Failure 2 (R1), fixed:** after fix 1, the reading effort matched, but the result still split 2 to 2 ("Made it" against "Made it, with effort"). SKILL.md had no rule for the difference. Fix (commit "Mission result: clear rules…"): Made it needs reading effort 1 and nothing blocking her. A cookie box covering the main button now counts as blocking, in line with the First look check. The next two runs agreed.

**Noted (R2):** Inbox was "Works" in one run and "Wobbly" in the other (one run flagged an abbreviation in the subject line). One check moving one step changes the score by at most 1, so this passes the roadmap rule.
